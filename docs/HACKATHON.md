# Hackathon requirements and schedule

Event notes recorded during setup on October 30, 2026. Recheck the [official participant guide](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/details) before deadlines or submissions. The official rules govern eligibility and judging.

## Project direction

- Event: Meta Global AI Developer Hackathon.
- Project: Coevo.
- Track and theme: Indie Developer / Build for Your World.
- Meaningfully use Meta Model API or Meta open-weight models in the result.
- Muse Code is a planned input adapter; the choice of development editor is separate from that product integration.

## Submission requirements

- Identify new functionality, code, and contributions created during the event. Demonstrate that work.
- Keep this submission repository fresh and limited to event implementation. Do not import a previous application codebase or its history. Explain prior concepts and new implementation in the demo.
- Provide a public GitHub repository, an accessible three-minute demo video, all contributors, and a submission through the event platform.
- Teams are limited to four members; contributors must satisfy the event's participant approval requirements.
- Avoid a basic RAG wrapper, a simple image analyzer, or a generic educational chatbot. Coevo should demonstrate the complete work-to-practice-to-evidence loop.
- Follow the official restrictions on prohibited domains, including medical, political, and warfare-related projects, and use only code/data with the required rights.
- Review dependency and model licenses. A project license has not yet been selected.

## Judging and awards recorded in the guide

1. Eligibility and baseline requirements, including theme fit and Meta model use.
2. Impact: 30%; use of Meta AI: 25%; technical depth/execution: 20%; demo: 25%.
3. The top five teams per track have their submitted videos reviewed at the final event.

The announced total prize pool is $1M. Indie awards were listed as $150K, $100K, $75K, $50K, and $25K for first through fifth. Potentially relevant bonus categories include Best Agentic Use-Case ($5K), Open Weight ($10K), and Creative ($5K), subject to the actual implementation and event rules.
